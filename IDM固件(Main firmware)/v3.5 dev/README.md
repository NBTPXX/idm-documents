# IDM v3.5 Dev Firmware

## ⚠️ IMPORTANT NOTICE / 重要提醒

**After flashing, the v3.5 firmware will require GENUINE VERIFICATION!**
**v3.5 固件烧录完成后，将会需要正版校验！**

Devices that FAIL verification will NOT work after flashing. Flash at your own risk!

未通过验证的设备刷入后无法正常使用，刷机风险自负！

### Genuine Verification / 正版校验

**https://idm.chimera3d.top**

## Files / 文件

| File 文件 | Communication 通信方式 | Baud 波特率 |
| --- | --- | --- |
| IDM_USB_v3.5_dev.bin | USB Serial / USB 串口 | — |
| IDM_CAN_250K_v3.5_dev.bin | CAN | 250K |
| IDM_CAN_500K_v3.5_dev.bin | CAN | 500K |
| IDM_CAN_1M_v3.5_dev.bin | CAN | 1M |

如需稳定固件，请使用 **v3.2** 文件夹。
